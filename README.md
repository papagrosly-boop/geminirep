# Conexión a la API de Google Gemini - Desarrollo de Aplicaciones con IA

Este repositorio contiene la implementación inicial para conectar y consumir la API de Google Gemini utilizando el SDK oficial `google-genai` en Python.

## 📁 Estructura del Proyecto

* `app_gemini.py`: Script de conexión inicial a la API de Gemini.
* `app_text.py`: Script para clasificación de tickets usando Few-Shot Prompting.
* `prueba_entorno.py`: Script para verificación del entorno virtual.
* `requirements.txt`: Dependencias del proyecto.
